<h1 align='center'> h5fortran </h1>

*h5fortran* is a Fortran library for reading and writing HDF5 files. 
It provides a simple and efficient interface for working with HDF5 files in Fortran, allowing users to easily read and write data in a variety of formats.

Supporting both the Serial HDF5 and the Parallel HDF5 for reading and writing.
